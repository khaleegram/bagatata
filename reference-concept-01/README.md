# Bagatata Technologies | Interactive Homepage Concept

An interactive, responsive first-pass homepage inspired by the existing Bagatata Technologies Limited gold ribbon-B brand. It is a static front-end concept for review, **not a deployed production website**.

## View it

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Included

- Real Bagatata ribbon-B crop from the established logo asset, not a newly generated emblem
- Responsive mobile/tablet/desktop layouts
- Gold orbital hero, typography, animation, responsive navigation
- Custom CSS UI illustrations for Loomis, EventTicketsNG, ChatCart and ArewaVanta
- Reduced-motion support, keyboard navigation, focus styles, active scroll progress
- Working outgoing links where actual platform domains are known
- Project inquiry modal, in **preview-only mode** (copies/downloads a draft; no network request)

## Before production launch

1. Replace illustrated product interfaces with approved product screenshots and real copy.
2. Confirm each platform's live link, offering and appropriate positioning.
3. Wire the inquiry form to a real server endpoint or approved email provider. It intentionally does not fake a submitted message.
4. Confirm final contact details, privacy policy, terms, analytics and SEO metadata.
5. Port the design into Next.js with components, optimized assets, content management and automated tests, if desired.
6. Review mobile performance, accessibility and cross-browser rendering.
